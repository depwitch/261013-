# 🏛️ 한능검 1급 마스터 (PassHistory)
> **한국사능력검정시험 심화(1~3급) 단기 합격 올인원 암기 & 실전 진단 솔루션**

---

## 🌟 주요 핵심 기능

### 1. ⚡ 시대별 직전 파이널 압축 암기 & 센스 기능
- **선사부터 현대사까지 전 시대 완벽 커버**:
  - 선사 & 고조선 · 초기 철기
  - 삼국 시대 & 가야
  - 남북국 시대 (통일신라 · 발해)
  - 고려 시대
  - 조선 전기 & 후기
  - 개항기 & 근대 사회
  - 일제 강점기
  - 현대사
- **🧠 두문자 암기 공식**: `부영고동 옥무동무`, `소태불율`, `법율불병공`, `병제병오신척`, `10헌태토 / 20보산치 / 30총황징` 등 뇌리에 박히는 암기 공식 제공
- **👁️ 블라인드 암기 모드 (Active Recall)**: 버튼 하나로 핵심 사료 키워드가 가려지며, 클릭 시 정답이 표시되어 시험 직전 자가 테스트 가능
- **🔥 킬러 비교 특강**: 
  - 신라 & 고려 승려 총정리 (원효 vs 의상 vs 혜초 vs 의천 vs 지눌)
  - 토지 제도 변천사 (녹읍 ➔ 전시과 ➔ 과전법 ➔ 직전법 ➔ 지주전호제)
  - 근대 불평등 조약 핵심 사료 비교 (강화도 ➔ 조미 ➔ 조청 ➔ 을사늑약)

### 2. 🚀 시험 직전 10분 벼락치기 치트키
- 시험장에 들어가기 직전 마지막 10분 동안 훑어보는 40대 단골 출제 키워드 카드
- 카드를 클릭하여 정답을 가리거나 볼 수 있는 스피드 플래시카드 기능

### 3. 📜 연표 인터랙티브 타임라인
- 기원전부터 2000년대까지 한능검에서 가장 자주 출제되는 사건의 전후 관계(가~나 사이 시기)를 완벽 대비하는 타임라인
- 시대별 필터링 지원

### 4. 🎯 실전 레벨 진단 테스트 & 맞춤형 능력 향상 처방
- 실제 한능검 심화(고급) 기출 20문항 실전 모의고사 (2점 / 3점 배점)
- 20분 타이머 및 실시간 OMR 답안지 인터페이스
- **정밀 진단 리포트**:
  - 취득 가능 급수 판정 (80점 이상 1급, 70점대 2급, 60점대 3급)
  - 시대별 성취도 분석 (레이더 프로그레스 바)
  - **맞춤형 처방전**: 가장 정답률이 낮은 취약 시대로 즉시 연결되는 핀포인트 복습 기능

### 5. 🤖 1:1 스마트 AI 역사 튜터
- 수험생이 헷갈리는 어떤 역사 질문이든 즉각적으로 1:1 답변
- 빈출 질문 퀵 버튼 원클릭 지원
- **핵심 정의 + 기출 출제 포인트 + 함정 선지 + 암기 비법**을 구조화하여 명쾌하게 해설

### 6. 🔍 스마트 초성 통합 검색
- 인물, 사건, 문화재, 제도 키워드 실시간 검색
- **초성 검색 지원**: `ㄱㅎㄷ` ➔ `강화도 조약`, `ㅈㄴ` ➔ `지눌`, `ㄷㄷㅂ` ➔ `대동법`

### 7. 📝 나만의 단권화 & 오답노트
- 모의고사에서 틀린 문제 자동 수집 및 상세 해설 제공
- 파이널 암기 노트에서 북마크한 중요 개념을 모아보는 나만의 단권화 요약장

## 💻 실행 방법

### 방법 1: 더블 클릭하여 바로 실행 (Zero-Dependency)
- `index.html` 파일을 크롬(Chrome), 엣지(Edge) 등의 웹 브라우저로 더블 클릭하여 바로 여시면 됩니다.
- 설치나 설정 없이 즉시 모든 기능이 동작합니다.

### 방법 2: 로컬 서버 실행
- PowerShell에서 프로젝트 폴더로 이동 후:
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\server.ps1
  ```
- 브라우저에서 `http://localhost:8085/` 로 접속하시면 됩니다.
